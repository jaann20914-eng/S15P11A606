# 와글와글 UX/UI 설계 명세

## 설계 원칙

요구사항 명세서를 최우선으로 적용했다. 핵심 정보와 다음 행동을 먼저 보여주고, 한 화면에는 하나의 주요 CTA만 강조한다. 라임 `#C4E600`은 CTA·선택·활성 상태에만 사용하고 그 위에는 `#3B3838`을 사용한다. 혼잡도는 브랜드색과 분리된 5단계 의미색으로 표현한다.

## 정보 구조

하단 내비게이션은 홈·추천·영상핀·채팅·마이의 5개다. 검색은 홈의 탐색 맥락에 포함하고, 장소 상세는 지도 줌인과 영상핀 목록을 통합한다. 영상 상세 안에서 3크레딧 열람, 평가 보상, 열람자 전용 채팅을 순서대로 제공한다.

## 상태와 예외

- 검색 결과 0개 상태
- 지도 API 미연동 플레이스홀더
- 위치 미선택 시 등록 차단
- AI 블러 처리 진행과 검수 실패 시 재촬영 정책 안내
- 열람 전 전체 블러와 열람 후 원본 상태
- 채팅 요청의 떠났어요·거절해요·수락해요
- AI 위험 대화 경고
- 신고는 MVP 정책에 따라 즉시 접수 버튼만 제공

## 요구사항 추적

- AUTH: OAuth 진입, 연령대·성별·닉네임 중복확인·선호 장소 1~4개
- HOME: 현재 위치 지도, 장소핀/목록 매핑, 여유·붐빔 필터, 최근 검색, 키워드·장소 검색
- LOCALPIN: 장소 줌인 지도, 기본정보, 요일 통계, 영상핀 목록
- VIDPIN/BLUR: 5초 실시간 촬영, 20m 장소 필수, 상세위치·메모·태그 선택, 5단계 혼잡도, 블러 조회, 수정·삭제, AI 처리
- CREDIT/VIEWP: 3크레딧 열람, 게시자 적립 개념, 평가 1크레딧, 뷰 반영 피드백
- CHAT: 열람 후 요청, 5크레딧 정산, 3가지 응답, 요청 상태, AI 경고
- MYP: 닉네임·뷰·크레딧·오늘 영상핀, 활동 히트맵, 작성 글, 크레딧 이력 필터, 닉네임 변경, 로그아웃
- REC: 선호 기반으로 여유로운 곳과 활기찬 곳을 분리 추천

## 시각 시스템

Pretendard 토큰을 기준으로 400·500·600·700의 위계를 사용하며 800 이상은 사용하지 않는다. 기능 아이콘은 Expo Ionicons의 16·20·24px 단색 아이콘이고, 생성형 3D 에셋은 72px 이상 대표 이미지로만 사용한다. 카드 반경은 20px, 히어로는 24px이며 그림자보다 배경과 여백으로 층위를 구분한다.

## 2차 시각 보정 규칙

- 기본 화면 배경은 흰색이며, 라임·블루 그라데이션은 콘텐츠가 적은 히어로와 완료·보상 상태에만 사용한다.
- 반복 데이터는 개별 카드로 쪼개지 않고 하나의 그룹 표면 안에서 행과 구분선으로 표현한다.
- 지도에는 선택 핀의 핵심 정보를 지도 위 미리보기로 겹쳐 탐색 맥락을 유지한다.
- 뷰 각도는 사용자 신뢰도를 나타내는 프로필 아바타다. 작성자, 채팅 상대, 마이페이지에 같은 원형 세그먼트 표현을 사용한다.
- 20px 바깥 여백, 12~16px 컴포넌트 내부 여백, 28~32px 섹션 간격을 기본 리듬으로 사용한다.
- 장소·영상·내역 행은 정보 삭제 없이 제목, 상태, 시간, 위치, 수치의 위계를 조정해 한 번에 훑을 수 있게 한다.
# 전역 레이아웃 및 그리드 시스템

- 기준 프레임은 390×844px이며, 실제 화면은 고정 폭이 아닌 유동형 레이아웃으로 구현한다.
- 모든 크기와 간격은 4px 베이스 그리드와 8px 중심 간격 시스템을 사용한다.
- 화면 좌우 여백은 기본 20px, 360px 미만 16px, 430px 이상 24px을 사용한다.
- 화면 그리드는 4컬럼, 컬럼 거터는 12px이다.
- 간격 토큰은 4, 8, 12, 16, 20, 24, 32, 40, 48px만 사용한다. 새로운 임의 간격을 만들지 않는다.
- 같은 그룹은 가깝게, 다른 그룹은 충분히 분리하며 구분선보다 여백을 우선한다.
- 주요 컴포넌트는 콘텐츠 폭을 채우며 고정 폭보다 Fill과 유동 폭을 우선한다.
- 상단 내비게이션은 56px, 주요 버튼은 56px/반경 16px, 보조 버튼은 44px/반경 12px이다.
- 입력창은 52~56px/반경 14~16px, 검색창은 48~52px이다.
- 카드는 반경 20px/내부 패딩 20px, 히어로 카드는 반경 24px/내부 패딩 24px이다.
- 바텀시트와 모달은 반경 24px이며 좌우 또는 내부 패딩은 각각 20px, 24px이다.
- 모든 인터랙션 요소는 최소 44×44px 터치 영역을 확보한다.
- Safe Area를 항상 반영한다. 하단 고정 CTA에는 하단 Safe Area를 포함한다.
- 지도는 전체 화면을 사용할 수 있으나 지도 위 UI에는 16~20px 안전 여백을 둔다.
