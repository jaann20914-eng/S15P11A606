# TIL - AI 혼잡도 분석(Crowd Analysis)

## 1. AI 혼잡도 분석이란?

AI 혼잡도 분석(Crowd Analysis)은 이미지나 영상 속 사람의 수와 밀집도를 분석하여 특정 장소가 얼마나 붐비는지를 판단하는 기술이다. 최근에는 공항, 지하철 역사, 놀이공원, 쇼핑몰, 공연장 등 사람이 많이 모이는 장소에서 많이 활용되고 있으며, 실시간 영상 데이터를 활용하여 사용자가 현장 상황을 미리 파악할 수 있도록 도와준다.

혼잡도 분석은 단순히 사람 수를 세는 기술이 아니라 객체 탐지(Object Detection), 영상 처리(Video Processing), 밀집도 계산(Density Estimation) 등의 컴퓨터 비전 기술이 결합된 기술이다.

시야확보 서비스에서는 사용자가 업로드한 실시간 영상을 AI가 분석하여 현재 장소의 상태를 자동으로 제공하는 기능에 활용할 수 있다.

---

## 2. 혼잡도 분석이 필요한 이유

시야확보 서비스의 핵심 목적은 "현재 장소의 실시간 상황을 사용자에게 제공하는 것"이다.

현재 사용자는 다음과 같은 정보를 알고 싶어한다.

- 사람이 얼마나 많은가?
- 줄은 얼마나 긴가?
- 지금 가도 괜찮은 상황인가?
- 많이 붐비는 시간대인가?
- 입장 대기가 발생하고 있는가?

하지만 사용자가 업로드된 영상을 직접 확인해야 한다면 시간이 오래 걸리고 상황을 판단하기 어렵다.

AI 혼잡도 분석을 활용하면 다음과 같이 간단한 정보를 제공할 수 있다.

```
현재 인원 : 약 20명
혼잡도 : 혼잡
예상 대기 : 약 10분 이상
추천 : 방문 비추천
```

즉, AI가 영상을 분석하여 사람이 직접 판단해야 하는 과정을 줄여줄 수 있다.

---

## 3. 혼잡도 분석 동작 과정

AI 혼잡도 분석의 전체적인 과정은 다음과 같다.

```
실시간 영상 업로드
        ↓
영상 프레임 추출
        ↓
객체 탐지 모델 실행
        ↓
사람 객체 탐지
        ↓
인원 수 계산
        ↓
밀집도 분석
        ↓
혼잡도 판단
        ↓
사용자에게 결과 제공
```

영상 전체를 한 번에 분석하는 것이 아니라 일정 시간마다 프레임(Frame)을 추출하여 분석하게 된다.

예를 들어 1초에 1장의 이미지를 추출하여 분석할 수도 있으며, 필요에 따라 0.5초 또는 2초 단위로 분석하는 방법도 사용할 수 있다.

---

## 4. 객체 탐지(Object Detection)

혼잡도 분석에서 가장 중요한 기술은 객체 탐지(Object Detection)이다.

객체 탐지는 이미지 속에서 특정 객체가 무엇인지 판단하고 위치를 찾아내는 기술이다.

예를 들어 영상 속에 다음과 같은 객체가 존재한다고 가정해보자.

```
- 사람
- 의자
- 자동차
- 가방
- 휴대폰
```

객체 탐지 모델은 각각의 객체를 구분하여 인식할 수 있다.

혼잡도 분석에서는 사람(Person) 클래스만 활용하면 된다.

객체 탐지 결과는 다음과 같이 표현된다.

```
Person - 98%
Person - 95%
Person - 97%
Person - 93%
```

즉, 영상 속에 사람이 총 4명 존재한다고 판단할 수 있다.

---

## 5. YOLO란?

혼잡도 분석에서 가장 많이 사용하는 객체 탐지 모델 중 하나는 YOLO(You Only Look Once)이다.

YOLO의 장점은 다음과 같다.

- 빠른 객체 탐지 속도
- 실시간 영상 분석 가능
- 다양한 객체 탐지 가능
- 사용 방법이 비교적 간단함
- 성능이 우수함

시야확보 서비스에서는 YOLO 모델을 활용하여 사람 객체를 탐지할 수 있다.

예를 들어 영상 속에 15명의 사람이 존재한다면 다음과 같이 결과를 얻을 수 있다.

```
Person 1
Person 2
Person 3
...
Person 15
```

이러한 결과를 바탕으로 혼잡도를 판단하게 된다.

---

## 6. 혼잡도 판단 방법

가장 간단한 방법은 사람 수를 기준으로 혼잡도를 계산하는 것이다.

예시)

```
0 ~ 5명      → 한산
6 ~ 15명     → 보통
16명 이상    → 혼잡
```

Python 코드로 표현하면 다음과 같다.

```python
if person_count <= 5:
    congestion = "한산"

elif person_count <= 15:
    congestion = "보통"

else:
    congestion = "혼잡"
```

하지만 실제 서비스에서는 장소마다 적정 인원이 다르기 때문에 단순한 사람 수만으로 판단하는 것은 한계가 있다.

---

## 7. 밀집도(Density) 분석

혼잡도 분석의 정확도를 높이기 위해서는 밀집도 분석이 필요하다.

예를 들어 다음 두 장소를 생각해보자.

```
대형 공연장 - 사람 30명

작은 카페 - 사람 30명
```

사람 수는 같지만 실제 체감 혼잡도는 매우 다르다.

따라서 다음과 같은 요소를 함께 고려할 수 있다.

- 사람 수
- 장소의 크기
- 사람 간 거리
- 줄 서 있는 인원 수
- 움직임 여부

이를 밀집도(Density) 분석이라고 한다.

즉,

```
혼잡도 = 사람 수 + 장소 크기 + 밀집도
```

와 같은 방식으로 분석 정확도를 높일 수 있다.

## 8. 실시간 영상 분석 방법

실시간 영상은 보통 다음과 같은 과정으로 처리된다.

```
영상 업로드

↓

1초마다 프레임 추출

↓

YOLO 실행

↓

사람 탐지

↓

사람 수 계산

↓

혼잡도 계산

↓

사용자에게 결과 제공
```

모든 영상을 분석하는 것이 아니라 일정 시간마다 이미지를 추출하여 분석하기 때문에 서버의 부담을 줄일 수 있다.
