# TIL - OpenCV (Open Source Computer Vision Library)

## 1. OpenCV란?

OpenCV(Open Source Computer Vision Library)는 이미지와 영상을 처리하기 위한 대표적인 컴퓨터 비전 라이브러리이다. 1999년 Intel에서 개발을 시작하였으며 현재는 오픈소스로 제공되고 있다.

Python, C++, Java 등 다양한 언어를 지원하며, 이미지 처리와 영상 분석 분야에서 가장 많이 사용되는 라이브러리 중 하나이다.

AI 모델(YOLO, OCR 등)을 사용하기 전 이미지나 영상을 전처리하거나, 카메라 데이터를 처리할 때 OpenCV를 활용하는 경우가 매우 많다.

---

## 2. OpenCV가 필요한 이유

시야확보 서비스에서는 사용자가 특정 장소의 사진이나 영상을 업로드하게 된다.

하지만 AI 모델은 사용자가 업로드한 영상을 그대로 사용하는 것이 아니라 다음과 같은 과정을 거친다.

- 이미지 불러오기
- 영상 프레임 추출
- 이미지 크기 조정
- 색상 변환
- 노이즈 제거
- 객체 탐지를 위한 전처리
- OCR을 위한 이미지 보정

즉, OpenCV는 AI 모델이 이미지를 잘 분석할 수 있도록 데이터를 가공하는 역할을 한다.

## 4. OpenCV 동작 과정

영상을 분석하는 과정은 다음과 같다.

```
영상 업로드

↓

OpenCV로 영상 읽기

↓

프레임 추출

↓

이미지 전처리

↓

AI 모델 실행

↓

분석 결과 생성

↓

사용자에게 결과 제공
```

예를 들어 사용자가 콘서트 현장의 영상을 업로드했다고 가정해보자.

```
콘서트 영상 업로드

↓

1초마다 이미지 추출

↓

이미지 크기 조정

↓

YOLO 실행

↓

사람 수 분석

↓

혼잡도 분석

↓

결과 출력
```

OpenCV는 AI 모델 이전 단계에서 영상을 처리하는 역할을 수행한다.

## 5. 이미지 처리 기능

### 이미지 불러오기

```python
import cv2

image = cv2.imread("image.jpg")
```

---

### 이미지 출력하기

```python
cv2.imshow("Image", image)
```

---

### 이미지 저장하기

```python
cv2.imwrite("result.jpg", image)
```

---

### 이미지 크기 변경

```python
resize_image = cv2.resize(image, (640, 640))
```

AI 모델들은 대부분 입력 이미지 크기를 맞춰줘야 하기 때문에 매우 자주 사용된다.

---

## 6. 영상 처리 기능

영상 파일을 읽어오는 방법은 다음과 같다.

```python
video = cv2.VideoCapture("video.mp4")
```

카메라를 사용할 경우에는 다음과 같이 사용할 수 있다.

```python
camera = cv2.VideoCapture(0)
```

영상은 여러 장의 이미지(Frame)로 구성되어 있기 때문에 OpenCV는 영상을 프레임 단위로 처리한다.

예시)

```
1초 영상

↓

30개의 Frame

↓

Frame마다 분석 수행
```

## 7. Frame 추출

혼잡도 분석에서는 영상 전체를 분석하는 것이 아니라 일정 시간마다 프레임을 추출하여 분석한다.

예를 들어 다음과 같이 사용할 수 있다.

```
30fps 영상

↓

1초마다 1장의 이미지 추출

↓

AI 분석

↓

혼잡도 계산
```

Frame을 추출하면 다음과 같은 장점이 있다.

- 서버 부담 감소
- 분석 속도 향상
- 실시간 처리 가능

## 8. 이미지 전처리(Image Preprocessing)

AI 모델의 성능을 높이기 위해서는 이미지 전처리가 필요하다.

대표적인 전처리 방법은 다음과 같다.

### Gray Scale

컬러 이미지를 흑백 이미지로 변환한다.

```python
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
```

활용 예시

- OCR
- 문자 인식
- Edge Detection

---

### Blur 처리

이미지의 노이즈를 제거한다.

```python
blur = cv2.GaussianBlur(image, (5,5), 0)
```

활용 예시

- OCR 정확도 향상
- 객체 탐지 정확도 향상

---

### Threshold 처리

이미지를 흑백으로 분리하는 작업이다.

```python
ret, thresh = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
```

활용 예시

- OCR
- 문자 추출
